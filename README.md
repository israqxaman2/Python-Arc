## About

Python Arc is the record of how I am learning Python, one project at a time. Every project here is something I built myself, from the very first small programs to the more ambitious applications I'm working toward. Each project lives in its own folder with a README that explains what it does, what I was trying to learn, and what I would improve next.

The repository is organized by difficulty so the progression is easy to see. Early projects are simple on purpose; the point is to show real growth, not to look more advanced than I am.

## Python Journey

I'm learning Python from the beginning. The plan is not a fixed curriculum: I choose projects that interest me and place each one by its actual complexity.

| Level | What it means here |
|---|---|
| **Beginner** | Core language fundamentals: variables, control flow, functions, basic data structures, small command-line programs |
| **Intermediate** | Multi-file programs, file handling, object-oriented design, working with external libraries and data |
| **Advanced** | Larger applications that combine several skills, such as APIs, databases, or automation |

## Skills & Concepts

This section lists only concepts that are demonstrated by a project in this repository. It will grow as the projects do.

- **Python fundamentals:** variables, user input, type conversion, arithmetic, modulo operator
- **Strings:** concatenation, f-strings, indexing and slicing, basic methods (`lower()`, `strip()`)
- **Control flow:** `if` / `elif` / `else`, nested conditions
- **Input validation:** rejecting invalid values with conditions
- **Formatted output:** f-strings and number formatting

## Repository Structure

Projects are grouped by level. Each level folder is created when its first project arrives.

```text
python-arc/
├── README.md
├── .gitignore
├── beginner/
│   └── project-name/
│       ├── README.md
│       └── project_name.py
├── intermediate/
└── advanced/
```

Conventions:

- Project folders use descriptive `kebab-case` names, such as `random-password-generator`.
- Python files use `snake_case`.
- Every project has its own `README.md` describing what it does, how to run it, and what I learned.

## How to Explore

1. Browse the [Projects](#projects) table for an overview.
2. Open a project folder and read its README first.
3. Run a project with `python file_name.py` (each README gives the exact command).
